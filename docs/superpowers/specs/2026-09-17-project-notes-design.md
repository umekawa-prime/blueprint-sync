# プロジェクトメモ（NOTE.md）

日付: 2026-09-17  
対象: Blueprint Sync（プロジェクト直下の課題 `TODO.md` を補うメモ）

## 背景

課題は `TODO.md` を Backlog 風の一覧として右パネルで編集できる。現場の走り書き・確認事項・課題にする前のメモを置く場所がない。

## ゴール

- プロジェクト直下の `NOTE.md` を正本にする
- 左サイドバーに `課題` と `メモ` を別項目として置く
- メモは Notion 風の行ブロック。クリックしてその場で編集。Enter で下に新しい行。左ハンドルで並べ替え
- 各行を課題化できる。行は残し、末尾に課題キー（例: `SITE-4`）を付けて `TODO.md` と紐づける

## やらないこと

- 入れ子（インデントした子行）
- 見出し・箇条書き・太字などのリッチテキスト
- 行 UUID のファイル永続化
- contenteditable のリッチエディタ
- JSON を正本にすること
- 同期プロトコルの追加（プロジェクト共有 ZIP はフォルダ内ファイルを既に全部入れる）

## データ

`NOTE.md` の例:

```markdown
# NOTE

- 現場で寸法を確認する
- 図面の赤字を反映する SITE-4
- 明日の朝礼で共有
```

1行が1ブロック。末尾トークンが既存の課題キー形式（`[A-Za-z0-9]{1,12}-\d+`）なら紐づけ済み。キーはパース時に大文字化する。メモリ上だけ DnD 用の一時 ID を持つ。

空ファイルまたは項目なしは、編集用に空行を1つ確保する。シリアライズは `# NOTE` のあと `- ` のリスト。

プロジェクトを開いたときファイルが無ければ作成する（`TODO.md` と同じタイミング）。閉じたらストアをリセットする。

## 画面と操作

左サイドバー下部に `課題` と `メモ` を別ボタンで置く。それぞれ右ドックを開き、対応する内容を出す。右パネル内のタブ切替はしない。サイドバーの「プロジェクトを閉じる」「プロジェクトを共有」は出さない（閉じるはタブの ×、共有はツールバー）。

右パネルのヘッダー:

- 課題一覧: 見出し `課題` と件数、右端に閉じる
- 課題詳細: 現行どおり `一覧へ` と閉じる
- メモ: 見出し `メモ`、右端に閉じる

メモの各行:

- 左ハンドルでドラッグして並べ替え（ポインタ。タッチでもハンドルから開始）
- 中央は1行テキスト。Enter でキャレット位置から分割して下行を作り、新しい行へフォーカス
- 空行で Backspace、かつ他に行があるときその行を消し、前の行へフォーカス。最後の1行は消さない
- 右端は未紐づけなら `課題化`。紐づけ済みなら課題キー。クリックで課題パネルを開き、その課題を選択する。キーが TODO に無い（削除済み）ときは同じ本文で新しい課題を作り、キーを付け直す
- 空行の課題化は何もしない

ツールバーの「課題」は課題パネルを開く。左サイドバーの各ボタンは `openTodoPanel`。

## 構成

- `src/lib/utils/noteMarkdown.ts` — パース、シリアライズ、行の追加／分割／削除／並べ替え／キー付与。座標計算は置かない
- `src/lib/utils/noteActions.ts` — `NOTE.md` の読み書き、課題化。コンポーネントから `invoke` しない
- `src/lib/stores/noteStore.svelte.ts` — 行配列。タブ状態は `todoStore.tab`
- `src/lib/components/NotePanel.svelte` — 行エディタ
- `src/lib/components/TodoPanel.svelte` — `todoStore.tab` が note のとき `NotePanel` を出す。タブ UI は持たない
- `chromeLayout` に `todoTab: "todo" | "note"` を保存

課題化は既存の `addProjectTodo(title)` を使う。新規課題の件名は行テキスト（キーを除く）。

## エラー

- プロジェクト未オープンでは読み書きしない
- 書き込み失敗は他のファイル I/O と同じく例外をそのまま出す（既存の todo と同じ）
- 不明な行（見出し以外の非リスト）はプレーンなメモ行として読む

## テスト

- パース／シリアライズの往復、末尾キーの抽出、空ファイル
- 行の並べ替え、Enter 分割、空行削除（最後の1行は残す）
- 未紐づけの課題化で TODO が増え、行にキーが残る
- 紐づけ済みは新規課題を作らず課題パネルへ切替
- 欠落キーは再課題化
- プロジェクトオープンで `NOTE.md` を作成／読み込み
- レイアウトテスト: 左サイドバーに `課題` と `メモ`。共有／閉じるは出さない
