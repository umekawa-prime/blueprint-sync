# プロジェクトと OneDrive リンク

日付: 2026-08-30  
対象: Blueprint Sync（現場オフライン向け PDF 図面編集・LAN 同期）

## 背景

いまのアプリは、1 つの PDF をメモリ上で開いて編集・同期する。プロジェクトも永続フォルダもなく、再起動すると注釈は消える。

現場ごとにローカルフォルダで図面とアプリデータをまとめ、メイン画面から OneDrive の共有リンクをブラウザで開けるようにする。

## ゴール

- 起動後は必ずプロジェクトを作成するか、既存フォルダを開く
- 指定したローカルフォルダに PDF とアプリ管理データを置く
- 1 プロジェクトに複数 PDF。一覧から選んで編集する
- メイン画面に OneDrive リンクを貼れる。押すと OS のブラウザで開くだけ
- 図面切替時と「保存」時に注釈をプロジェクトフォルダへ書き出す

## やらないこと

- OneDrive からのダウンロード、同期、クラウド認証
- プロジェクト間の図面コピー
- 注釈の自動定期保存
- `pdfjs-dist` によるページ描画、Fabric オーバーレイの座標計算、`pdf-lib` 合成ロジックの書き換え

「PDF レンダリングの中身」とは、図面をキャンバスに描く既存エンジン（`pdfRenderer.ts` / `PdfViewer.svelte` の描画部分）を指す。今回変えるのは「どのファイルのバイト列を、いつ読むか」だけ。描画の見え方は変えない。

## 起動フロー

1. 起動直後はプロジェクト画面だけを出す（図面キャンバスは出さない）
2. **新規作成**: 名前を入力し、ローカルフォルダを指定。その中に `.blueprint-sync/` を作る
3. **開く**: `.blueprint-sync/project.json` があるフォルダを選ぶ
4. プロジェクト確定後に、現行の編集画面へ入る
5. 「プロジェクトを閉じる」で起動画面に戻る

最近使ったプロジェクトは OS のアプリ設定にフォルダパスを数件覚える。起動画面に一覧を出し、クリックで開ける。フォルダが消えていたら一覧から外す。

## フォルダ構成

```text
<指定フォルダ>/
  1F平面図.pdf
  2F平面図.pdf
  .blueprint-sync/
    project.json
    annotations/
      <pdfファイル名>.json
```

- PDF はフォルダ直下。一覧はこの階層だけをスキャンする（サブフォルダは見ない）
- `.blueprint-sync/` は一覧から除外する
- 「開く」で追加した PDF は、このフォルダへコピーする。すでに同じフォルダ内のファイルならコピーしない

## メイン画面

現行のツールバー＋キャンバス＋接続パネル＋ステータスバーは残す。左にサイドバーを足す。

- プロジェクト名
- フォルダ内 PDF 一覧。クリックで図面を切り替える
- OneDrive リンク: 入力欄と追加ボタン。一覧項目をクリックしたらブラウザで開く。削除できる
- 「プロジェクトを閉じる」

## データ

### `project.json`

```json
{
  "id": "uuid",
  "name": "現場A",
  "createdAt": "2026-08-30T08:00:00.000Z",
  "links": [
    { "id": "uuid", "title": "共有フォルダ", "url": "https://1drv.ms/..." }
  ]
}
```

- `links[].url` は `http` または `https` のみ。それ以外は追加を拒否する
- タイトルが空なら、一覧では URL を表示する
- リンクの追加・削除はすぐ `project.json` に書き込む
- ブラウザ起動は Tauri opener を使う。取得や同期はしない

### 注釈

- 図面切替時とツールバー「保存」時に `.blueprint-sync/annotations/<pdf名>.json` へ書く
- `<pdf名>` にパス区切り（`/` `\`）と `..` を含めてはならない
- 同じ PDF を開き直したら、その JSON から復元する
- 既存の「保存」（注釈を合成した PDF の書き出し）は残す。書き出し先の初期値はプロジェクトフォルダ
- 注釈の書き込みに失敗したらステータスバーに出し、メモリ上の編集は残す

### 最近使ったプロジェクト

アプリ設定（Tauri / OS app data）に、開いたフォルダパスを新しい順で最大 8 件保持する。

## 失敗時

- フォルダが読めない／書けない: メッセージを出してプロジェクト画面に戻す
- 既存フォルダを開いたが `project.json` が無い: 作成せず、エラーを出す
- リンクが `http(s)` 以外: 追加しない
- 最近使ったパス先が無い: その項目を一覧から外す

## 実装範囲

追加:

- `ProjectHome.svelte` — 新規作成、最近使ったプロジェクト、既存フォルダを開く
- `ProjectSidebar.svelte` — PDF 一覧、OneDrive リンク、プロジェクトを閉じる
- `projectStore` — 現在のプロジェクト、PDF 一覧、リンク、最近使ったパス
- Rust コマンド — フォルダ選択、ディレクトリ一覧、ファイル読み書き、URL を opener で開く
- ユーティリティ — `project.json` / 注釈 JSON の読み書き、URL 検証、注釈ファイル名の安全化

変更:

- `+page.svelte` — 未選択なら起動画面、選択後はサイドバー＋現行エディタ
- `Toolbar.svelte` — 「開く」はプロジェクトフォルダへ PDF を追加。「保存」の初期先はプロジェクトフォルダ
- `pdfStore` / `annotationStore` — 図面切替時に注釈をディスクへ保存／復元
- `fileAccess.ts` — プロジェクト配下の読み書きに寄せる

フォルダ選択・ディレクトリ一覧・ブラウザ起動は Tauri 実行時のみ。`npm run dev` のブラウザ単体ではプロジェクト機能は使えない（現行のホスト機能と同じ制約）。

## テスト

- `project.json` の読み書きと不正データの拒否
- OneDrive URL は `http` / `https` のみ通す
- 注釈ファイル名がパス区切りや `..` を含まない
- フォルダ内 PDF の一覧で `.blueprint-sync` を除外する

## 承認済みの判断

- OneDrive リンクはブラウザで開くだけ。実体はローカルフォルダで管理する
- 起動はプロジェクト必須（作成または既存を開く）
- 1 プロジェクトに複数 PDF。フォルダ直下の一覧から選ぶ
- 管理データは指定フォルダ内の `.blueprint-sync/` に置く
