# Chrome 型ウィンドウ枠

日付: 2026-09-06  
対象: Blueprint Sync（Tauri デスクトップ）

## 背景

プロジェクトタブをウィンドウ最上段に置いたが、その上に OS のタイトルバーが別段ある。Chrome / Edge のように、タブバー自体をタイトルバーにして動かしたい。

## ゴール

- デスクトップ Tauri では OS の枠（`decorations`）を外す
- タブバー右端に最小化・最大化・閉じる
- タブ・`+`・ウィンドウボタン以外の空きをドラッグして移動。ダブルクリックで最大化／復元
- プロジェクト 0 件でも、デスクトップ Tauri ではこのバーを出す（枠が無いとウィンドウをつかめない）
- ブラウザと Android / iOS ではウィンドウボタンを出さない。ブラウザのタブバーはタブがあるときだけ（現行）

## やらないこと

- Windows 11 のスナップレイアウトフライアウト専用プラグイン
- 透明ウィンドウ、常に最前面
- ブラウザで自前の最小化ボタンを出す

## 画面

`[タブ…][+]` → 空き（ドラッグ）→ `[− □ ×]`

タブが無いときは左に「Blueprint Sync」、残りがドラッグ、右がウィンドウボタン。

## 権限

`core:window:allow-start-dragging` / `allow-minimize` / `allow-toggle-maximize` / `allow-close`

ウィンドウ API は `src/lib/utils/windowActions.ts`。コンポーネントから `invoke` しない。
