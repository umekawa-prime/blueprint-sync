# 図面メモピン（テキストツール置き換え）

日付: 2026-09-18  
対象: Blueprint Sync

## 背景

ツールバー「テキスト」は Fabric の `IText` を図面キャンバスへ置き、出力時に PDF へ焼き込む。現場の指摘はピン位置に紐づけたい。写真ピンは既に HTML オーバーレイだが、写真専用である。

## ゴール

- 「テキスト」クリックはメモピン（ピン＋吹き出し）を置く
- 図面上で本文が見え、クリックで編集できる
- 出力 PDF の同じ図面ページにピンと吹き出しを焼き込む
- 写真ピンの番号・スライド・カメラは変えない
- 既存の Fabric 文字は残し、選択ツールで動かす・消す

## やらないこと

- 古い `IText` の自動変換
- メモの番号（①）や別スライド
- 吹き出し背景色の永続化
- 同期プロトコルの新メッセージ（注釈 JSON に載せる）
- メモの undo / redo
- 写真ピンとの統合

## データ

注釈 JSON に `memoPins` を足す。キーが無ければ空。

```json
{
  "byPage": {},
  "photoPins": {},
  "memoPins": {
    "0": {
      "memo-1": {
        "id": "memo-1",
        "nx": 0.42,
        "ny": 0.31,
        "text": "梁成を現場で確認",
        "color": "#E81123",
        "createdAt": 1773760000000
      }
    }
  }
}
```

- `(nx, ny)` はピン先端。写真ピンと同じ正規化座標
- `text` は文字列。置いた直後は空。フォーカスを外したとき空ならピンを消す
- `color` は `#RRGGBB`。文字色パレット。不正・欠落は `#E81123`
- 吹き出し塗りは白。JSON に背景は持たない
- `createdAt` は置いた時刻。無い古いデータはオブジェクト順で補完

シリアライズは常に `memoPins` を書く。

## 画面と操作

- 「テキスト」で図面の空きをクリック → その位置にピンを置き、吹き出しを編集状態にする → ツールは選択に戻す
- 既存 Fabric オブジェクト上のクリックではピンを置かない
- 吹き出しまたはピンをクリックで編集。文字色パレットは編集中のピンに効く
- 写真ピンと同じドラッグ（マウスは移動、タッチは長押し）
- 右クリック（タッチは長押しメニュー）で削除
- 本文は 1 行 12 文字、最大 4 行。超えたら末尾を `…`
- 吹き出しはピンの右。右端に近いときは左
- 写真ピンレイヤーの上に重ねる

## 出力

`exportOverlays` で Fabric PNG のあと、同じページにメモピン PNG を重ねる。写真ピン番号マーカーとは別 PNG。座標計算は `memoPinLayout.ts`。コンポーネントに座標を置かない。

## 構成

- `annotationPersist.ts` — `MemoPinRecord`、parse / serialize
- `memoPinLayout.ts` — 折り返し、先端・円・吹き出し矩形、PNG
- `annotationStore` — add / update / remove / import / export
- `MemoPinLayer.svelte` — 表示・編集・移動
- `PdfViewer.svelte` — テキストツールで置く。IText 新規作成をやめる
- `projectIo.writeAnnotationFile` / `persistCurrentAnnotations` / タブセッション

## エラー

- 不正なメモは読み飛ばす（ページ全体は落とさない）
- 注釈ファイル全体が壊れているときは現行どおり空で開く
- 出力 PNG が作れなければそのページのメモは焼かない（Fabric 注釈は出す）

## テスト

- パース往復、欠落 `memoPins`、不正色の既定値、空文字
- 折り返し、先端座標、右端で吹き出しが左へ
- ストアの追加・移動・空テキスト削除・clear
- レイアウト: `MemoPinLayer`、テキストツールが `addMemoPin`、`new IText("テキスト"` が無い
