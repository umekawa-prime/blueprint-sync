# ペンの消しゴムと図形ドラッグ

日付: 2026-09-28  
対象: Blueprint Sync（図面注釈）  
前提: ペンの直線・先端（`2026-09-08-pen-straight-stroke-design.md`）。消しゴムの当たり規則は `2026-09-17-android-share-and-pen-eraser-design.md` のペンモードに合わせる。図形はこの仕様で足す。

## ゴール

- ペンまたは消しゴムのとき、描画ツールはペンと消しゴムだけ。完了で選択に戻る
- 消しゴムはペンの1ストロークに当たったら、その Fabric オブジェクトを分割せず丸ごと消す
- 通常時は矩形・楕円・矢印線が独立したツールとして常に見える
- 図形はドラッグで描く。色と太さは今のペン設定。塗りつぶしはしない

## やらないこと

- ピクセル消しゴム、線の途中だけ消すこと、テキストや写真ピンの削除
- 消しゴムで矩形・楕円・矢印線を消すこと
- 塗りつぶし、Shift による正方形・正円、描いたあとの見た目変更
- ペンの色・太さ・先端パレットの作り直し
- 図形をペンモードの中に出すこと

## ツールバー

通常の描画ツールは「選択 / ペン / テキスト / 移動 / 矩形 / 楕円 / 矢印線」。

現在のツールがペンまたは消しゴムのときは「ペン / 消しゴム / 完了」だけにする。選択、テキスト、移動、図形はこのあいだ出さない。保存・カメラ・その他は残す。完了で選択に戻す。

スタイラスの消しゴム端（`pointerType === "eraser"`）は、ペンまたは消しゴムのとき消しゴムにする。図形ツールのあいだ、スタイラスのペン先は図形ツールのままにする。

## 消しゴム

1ストロークは、ペンの1回の描画でできた Fabric オブジェクト1つである。

- フリーハンドの Path。先端があるときはそれを包む Group ごと
- Shift＋クリックの直線／折れ線が返したオブジェクト1つ

当たったら `canvas.remove` する。ドラッグで複数に当たったら、当たった順にそれぞれ一度だけ消す。消した線は既存の `object:removed` で戻り、LAN 同期の remove も現行と同じ。

消さないもの: テキスト、写真ピン、PDF 本体、および `annotationRole === "shape"` のオブジェクト（矩形・楕円・矢印線）。

ヒットは線の中心線から線幅の半分以内。当たり判定は `src/lib/utils/` に置く。

## 図形

矩形・楕円・矢印線は、押した点から離した点までのドラッグ。移動距離が 6 未満なら破棄する。描いたあとも同じツールのまま。

- 矩形: 2点を対角とする枠線
- 楕円: その矩形に内接する枠線
- 矢印線: 押した点から離した点へ向き、先端だけ矢印。始点の先端は付けない

色と太さは `toolStore.penColor` と `penWidth`。塗りは透明。オブジェクトに `annotationRole: "shape"` を付け、注釈 JSON の `toObject` に載せる。履歴と同期は既存の add と同じ。

## 配置

- 表示するツール一覧: `src/lib/utils/drawingTools.ts`
- ドラッグの採否と矩形: `src/lib/utils/shapeDraw.ts`
- Fabric オブジェクトの生成: `src/lib/utils/shapeFabric.ts`
- 消しゴムのヒット: `src/lib/utils/strokeHit.ts` と `src/lib/utils/strokeEraser.ts`
- 画面への配線: `Toolbar.svelte` と `PdfViewer.svelte`。座標計算は `.svelte` に書かない

## テスト

- ペンモードのツール一覧に選択・テキスト・移動・図形がない
- 6 未満のドラッグは図形にならず、対角と矢印の向きは押した点と離した点のまま
- 消しゴムは Path / 折れ線 / 先端 Group に当たり、テキストと `shape` には当たらない
- 図形オブジェクトは `annotationRole` が `shape`
