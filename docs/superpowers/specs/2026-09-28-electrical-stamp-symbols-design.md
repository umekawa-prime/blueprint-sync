# 電気設備のスタンプ記号

日付: 2026-09-28  
対象: Blueprint Sync（図面注釈）  
前提: ドラッグ図形（`2026-09-28-pen-eraser-and-shapes-design.md`）。ペン色は既存の `toolStore.penColor`。

## 背景

電気設備図では照明・コンセントなどを決まった記号で図面に打つ。矩形・楕円・矢印線のドラッグ作図とは別に、クリックで置くスタンプが要る。

## ゴール

- 通常ツールバーは「選択 / 図形 / ペン / テキスト / 移動 / 矩形 / 楕円 / 矢印線」
- 図形を選ぶとパレットで設備記号を選び、クリックした位置の中心に置く
- 同じ記号を、選択など別ツールに戻るまで連続で置ける
- 色は今のペン色。大きさはページ幅に対する固定比。置いたあとは選択ツールで移動・拡大縮小・削除できる
- 既存の矩形・楕円・矢印線は残す

## やらないこと

- ドラッグでスタンプの大きさを決めること
- S/M/L サイズ、独自の色パレット
- JIS 全記号、文字入りスイッチ（S）、塗りつぶし以外のハッチ
- 置いた記号の色・種類のあとからの変更（選択で変形するだけ）
- ペンモード中に図形を出すこと
- 消しゴムでスタンプを消すこと（今の shape と同じ）

## 操作

1. 図形を押すとスタンプツールになり、パレットが開く
2. 照明 / シーリング / ダウンライト / コンセント / スイッチ / 分電盤から選ぶ
3. 図面をクリックすると、その点を中心に選中の記号を置く
4. ツールはスタンプのまま。別の記号を選ぶと次からそれが置かれる
5. 選択に戻すと移動・拡大縮小・Delete ができる

スタイラスのペン先はスタンプ中にペンへ奪われない。

## 記号

いずれも枠線。塗りはダウンライトの内側だけ。線幅は今の `penWidth`。

| id | 表示名 | 形 |
|---|---|---|
| `light` | 照明 | ○（円） |
| `ceiling` | シーリング | ◎（同心円） |
| `downlight` | ダウンライト | 円＋内側の塗り円 |
| `outlet` | コンセント | 円にバツ |
| `switch` | スイッチ | 正方形 |
| `panel` | 分電盤 | 横長の矩形＋対角 |

初期選択は `light`。大きさはページ幅の 2.8%（下限 16px）。ズームし直したキャンバスでもページに対して同じ大きさになる。

## データ

Fabric の Group（必要なら単体も Group）として既存の注釈 JSON に載せる。`annotationRole: "shape"` を付け、消しゴムは今の矩形と同じく無視する。履歴・同期・PDF PNG 重ねは既存の add と同じ。

## 配置

- 記号の種類とジオメトリ: `src/lib/utils/stampDraw.ts`
- Fabric 生成: `src/lib/utils/stampFabric.ts`
