# ピン番号と写真スライド出力

日付: 2026-09-12  
対象: Blueprint Sync（図面ピンの番号表示と PDF 保存）

## 背景

図面に写真ピンを置ける。保存時は図面ページの直後へピン写真のスライドを差し込んでいるが、図面上のピンは HTML オーバーレイのため PDF に載らない。ピンと写真スライドの対応も番号では分からない。

## ゴール

- 同じ図面ページ内で、置いた順に ① から番号を振る
- 編集画面のピンの下に、その番号を出す（丸いサムネはそのまま）
- 保存した PDF の図面ページにも、同じ位置・同じ番号のマーカーを焼き込む
- 直後の写真スライド見出しは `①`、タイトルがあれば `① 基礎`
- ピンを消したら、残ったピンを置いた順で ① から詰め直す
- ページが変わればまた ① から

## やらないこと

- 番号をピン JSON に保存する（`createdAt` だけ持つ。番号は都度計算）
- 編集画面のピンを番号だけのマーカーに変える
- 位置順での番号付け
- 欠番を残す
- 保存ボタン以外の「書き出し」ダイアログ

## データ

`PhotoPinRecord.createdAt` はミリ秒。新規は置いた時刻。同じミリ秒なら `max + 1`。番号は保存しない。

古い JSON に `createdAt` が無いピンは、そのページのオブジェクト順で 1, 2, 3… を仮に付ける。新規ピンの `Date.now()` より小さいので、後から足したピンが後ろの番号になる。

同着は `id` で安定ソート。

表示ラベルは ①–⑳、㉑–㉟、㊱–㊿。51 以上は `(51)`。

## 編集画面

ピン先端（白い三角の先）を `(nx, ny)` に置く。その下に番号ピル、その下にタイトル（あれば）。サムネの丸と三角は今どおり。

`PhotoPinLayer` は `numberedPins` の順で描く。座標計算はコンポーネントに足さない。

## PDF 保存

1. 現行どおり Fabric 注釈を PNG にしてページへ重ねる
2. 同じキャンバスサイズでピンマーカー（サムネ・三角・番号）を PNG にし、同じページへ重ねる
3. 図面ページの直後へ、番号順の写真スライドを差し込む。見出しは `pinSlideCaption`

JWW など CAD パスは今どおり PDF を上書きしない。

## テスト

番号ラベル、`createdAt` の補完と一意化、削除後の詰め直し、スライド順と見出し、マーカー先端が `(nx, ny)` にあること。キャンバス描画のピクセル比較はしない。
