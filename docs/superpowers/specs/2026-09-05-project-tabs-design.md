# プロジェクトタブ

日付: 2026-09-05  
対象: Blueprint Sync（現場オフライン向け PDF 図面編集・LAN 同期）

## 背景

いまのアプリはプロジェクトを1つだけ開く。起動画面と編集画面は入れ替わりで、別現場を見るには今のプロジェクトを閉じる必要がある。ブラウザのように複数現場をタブで行き来したい。

## ゴール

- 複数プロジェクトをタブで同時に開く
- タブバーはウィンドウ最上段。右端に固定の `+`
- `+` はすぐフォルダ選択。キャンセルではタブを増やさない
- 選んだフォルダに `project.json` がなければその場で作成して新しいタブで開く
- 同じフォルダは既存タブへ切り替える
- 最後のタブを閉じると起動画面に戻り、タブバーは消える
- 表示中のタブだけ pdf.js / Fabric キャンバスを動かす。非表示タブはセッション（フォルダ、図面、注釈、履歴、ページ／ズーム、PDF バイト）として残す

## やらないこと

- アプリ再起動後のタブ復元
- タブごとの PdfViewer / pdf.js ドキュメントの常駐
- 同じプロジェクトを2タブで開く
- LAN 接続をタブごとに分ける（接続はアプリ全体で1本、同期は表示中タブ）
- ペン／消しゴム機能
- PDF 描画エンジン（`pdfRenderer.ts` / Fabric 描画本体）の書き換え

## 画面

起動直後とタブ 0 件のときは、現行の起動画面だけを出す（タブバーなし）。

プロジェクトが1つ以上開いているとき、ウィンドウ一番上にタブバーを置く。その下は現行どおり左サイドバー＋ツールバー＋キャンバス。サイドバーとツールバーは表示中タブのプロジェクトだけを示す。

各タブはプロジェクト名と `×`。`+` はバー右端に固定し、タブが増えて横スクロールしても動かない。

サイドバーの「プロジェクトを閉じる」は、表示中タブの `×` と同じ。

## データ

`projectStore` がタブ一覧と表示中タブ ID を持つ。表示中タブのフォルダ／メタ／PDF 一覧／現在の図面／エラーは、現行どおりストアのライブフィールドとしても見える（既存の代入・テストを壊さない）。

各タブのセッション:

- フォルダ、`project.json` メタ、PDF 一覧、開いている図面
- 注釈（`byPage` / `photoPins`）と編集履歴
- PDF バイト、ページ、ズーム、ステータス
- pdf.js の `PDFDocumentProxy` は含めない。切替時にバイトから再ロードする

`recents`、ペン、LAN 接続はアプリ全体のまま。タブは起動中だけ。再起動後は起動画面。

フォルダの同一判定は既存の `normalizeFsPath`（区切り正規化＋末尾スラッシュ除去＋小文字化）を使う。

## 操作

### 起動画面から開く／作成する

成功したらタブが1つ付き、編集画面へ入る。中身は現行の `openProject` / `createProject` / 最近使った項目と同じ。失敗時も現行どおり起動画面にエラーを出す。

### `+`

1. フォルダ選択をすぐ開く
2. キャンセル → 何もしない
3. 既に開いているフォルダ → そのタブへ切替
4. `project.json` がある → そのプロジェクトを新しいタブで開く
5. ない → そのフォルダでプロジェクトを作成し、新しいタブで開く

新しいタブを載せる直前に、表示中タブの注釈をディスクへ書き、ライブ状態をそのタブのセッションへ退避する。新規の読み込みや作成が失敗したときは、既存タブを閉じない。エラーはステータスバーに出す。

### タブ切替

表示中タブの注釈を保存してセッションへ退避し、行き先のセッションをライブストアへ戻してキャンバスを載せ直す。保存に失敗したら切替しない。

### タブを閉じる

表示中タブなら注釈を保存してから捨てる。保存失敗なら閉じない（現行の `closeProject` と同じ）。非表示タブは、前回切替時に保存済みなので捨てるだけ。

残ったタブがあれば隣（閉じたタブの右、なければ左）を表示する。0 件ならストアをリセットして起動画面へ戻る。

## エラー

| 状況 | 結果 |
|---|---|
| フォルダ選択キャンセル | タブも画面も変えない |
| 同じフォルダを再度開く | 既存タブへ切替 |
| 2件目以降の open / create 失敗 | 既存タブは残す。ステータスバーに理由 |
| 起動画面での open 失敗 | 現行どおり起動画面にエラー。recent から消す条件も現行どおり |
| 注釈保存失敗（切替・閉じる） | 中止。ステータスに理由 |
| 最後のタブを閉じる | 起動画面。タブバーなし |

## テスト

- タブ一覧の追加・同一フォルダ検出・閉じたあとの次タブ・最後の1つを閉じる、は純粋関数で単体テストする
- `openProject` / `createProject` / `closeProject` の既存テストは通す。ライブフィールド（`folder` / `meta` / `pdfs` / `currentPdf`）は今と同じ代入で触れる
- 追加: `+` 相当の開く処理がキャンセルでタブを増やさない、既存タブへ切替、未初期化フォルダは作成、失敗しても他タブを消さない、最後のタブを閉じると `isOpen === false`
- `pdfRenderer.ts` と Fabric 描画のテストは触らない
