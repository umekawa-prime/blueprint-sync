# テキストの背景色

日付: 2026-09-08  
対象: Blueprint Sync（図面注釈）

## 背景

図面上の文字は線の上に重なると読みにくい。文字色はペン色を流用しており、背景は付けられない。置いたあとに色を変える手段もない。

## ゴール

- 「テキスト」の横に、ペンとは別の色パネルを出す
- 文字色と背景色を選べる。背景の初期値はなし（透明）
- 文字色の初期値は現行どおり赤 `#E81123`
- 何も選んでいないときは、次に置く文字の設定になる
- 文字を選択中は、その文字の色がパネルに出る。パネルで変えるとそのテキストボックスにすぐ反映する
- 背景ありのときだけ、文字の周りに余白を付ける
- ペンの色・太さ・先端は独立。テキストパネルで色を選んでもペンには切り替わらない

## やらないこと

- 複数選択への一括適用
- 枠線・角丸・不透明度スライダー
- 既存テキストの一括変換
- ペンパネルへの背景色追加
- フォントサイズ変更

## 操作

1. 「テキスト」横の見本を開く
2. 文字色／背景色を選ぶ。背景は「なし」も選べる
3. 文字が選択されていれば、そのオブジェクトを更新する。選択がなければテキストツールのまま、次のタップでその設定の文字を置く
4. 選択ツールで文字を選ぶと、パネルが見本をその文字の色に合わせる

## データ

Fabric `IText` の `fill` / `backgroundColor` / `padding` を使う。背景なしは空文字。背景ありの padding は 6。既存の注釈 JSON・履歴・LAN・PDF 重ね書き出しは `toObject` のまま。旧データに `backgroundColor` が無ければなし扱い。
