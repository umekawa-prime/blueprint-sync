# ペン直線と先端形状

日付: 2026-09-08  
対象: Blueprint Sync（図面注釈）

## 背景

現場図面では引出線・寸法線として、フリーハンドではなく頂点クリックの直線が要る。始点と終点に黒丸や矢印を付けたい。ツールバーはペンをクリックして色・太さ・先端をまとめて選びたい。

## ゴール

- ペンツールのまま、キーボードで Shift を押しながらマウスをクリックすると頂点が打たれる
- 2点なら直線、3点以上なら折れ線。Shift を離すと確定し、フリーハンドに戻る
- Shift を離したあと、再度 Shift＋クリックすると別の線になる
- 始点・終点の形は独立（なし / 黒丸 / 矢印）。線の色は1色。矢印はその色、黒丸は常に黒
- ペンをクリックするとパネルが開き、色・太さ・始点・終点を選ぶ
- 設定は次に書く線にだけ効く。書いた線はあとから変えない
- フリーハンドにも同じ先端設定が付く
- タッチ／スタイラスは従来どおりフリーハンドのみ

## やらないこと

- ホバーで開くツールバー
- 書いた線の再スタイル
- タッチ端末用の直線トグル
- 45度スナップ
- 蛍光ペンなど別の描画ツール

## 操作

1. ペンを選ぶ
2. Shift を押すとフリーハンドは止まる
3. マウスで点をクリック（2点以上）
4. Shift を離すと1本の線として保存。1点以下なら破棄
5. Esc は途中の頂点を破棄してフリーハンドに戻す

## データ

線と先端は Fabric の1オブジェクト（先端があるときは Group）として既存の注釈 JSON に載せる。PDF 書き出しは今どおり PNG 重ねなので見た目が正しければ足りる。
